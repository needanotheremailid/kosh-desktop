Agent control

Codex or Claude can use agent.py through the same validated local service. It needs your permission for the named workspace, files and writes.

Start the desktop app, then use python.exe agent.py --help from the app folder. Read AGENT_API.md for exact commands. The CLI reads the private launch token without printing it.

Agents cannot flush an unsaved browser draft. Save before agent exports/backups. Optional installed-agent help previews Kosh-supplied content and requires consent per request, then returns proposed text. Its provider may receive that content outside this computer; the CLI can add its own instructions or environment information. UI approval uses your explicit checkbox. CLI approval flags attest caller authorization; Kosh cannot verify that a human approved a CLI request. Chosen-folder text editing is a separate local diff/approval flow with retained originals. No arbitrary command executor or formal screening is enabled.

Help with Kosh

A local workspace for reading, source-linked notes and writing.

Discover references

Choose Discover references in More and type a public search query. Only that submitted query goes to PubMed, Crossref, Europe PMC or OpenAlex. Add reference metadata saves a catalogue bibliography record, not a full paper. Verify publication fields before submission.

Sources & reading

Import selected PDF, Word, text, Markdown, BibTeX or CSV files. A managed copy is retained locally. Review receipts for failures and incomplete text. Search uses extracted active-source passages. Archive hides a source while retaining data. PDFs offer file-page images; other files use text sections. The explicit OCR copy action creates a separate derivative when local OCR is available.

Find your writing

Find drafts in Write and Find notes in the Notes panel search titles and Markdown bodies in this workspace, including unsaved text in this window. Every search word must match; case and accents are ignored. Sort by last saved date or title. Filtering keeps the current draft open. Clear search or press Escape in a non-empty search to restore the list. Switching workspace clears the search. Selecting a result moves keyboard focus to its title.

Writing & references

Write Markdown notes with autosave. Insert a source locator from Read, then open that locator to check the evidence. Blank outlines append headings by your explicit choice. Writing check reports saved-note mechanics and missing bibliography fields. Source details may be entered by you or imported from a catalogue; check them against the publication. Offline CSL styles format your publication metadata; they cannot invent absent fields. Journal styles can be imported in Exports & backup.

Ask sources

Choose source excerpts for a no-AI retrieval response, or an installed local Ollama model. Only selected excerpts form the model context. A citation is a route back to evidence, not proof of a claim. Answers without valid citations are marked unsupported. Installed Codex and Claude help is a separate preview-and-send option. Their authenticated providers may receive Kosh-supplied content outside this computer and incur usage. The CLI may add its own instructions or environment information; configured suppression is not proof of the complete outbound request. Detection is not sign-in or model-readiness proof.

Evidence matrix

Record a question, study design, findings and limitations attached to a source. These are your manual notes; the app does not conduct formal screening or verify extracted study data.

Save & recover

Pending edits save before navigation and exports. If another writer changed a note, both versions can be preserved as separate notes. Browser recovery retains unsaved drafts. Resolve conflicts before quitting; closing while dirty may lose edits if browser storage is cleared.

Exports, backup & agents

Writer export buttons export the current saved draft and its cited references. Exports & backup exports all saved workspace writing. BibTeX and CSV export source metadata and evidence. ZIP backups retain originals and saved records. Optional revision history increases backup size. Restore validates a ZIP and creates a separate workspace. Agents use the local CLI with your permission; save browser edits before agent work.

Chosen-folder editing

Choose an explicit existing folder and propose full UTF-8 text replacements. Preview exact diffs, hashes and any line-ending or UTF-8 BOM changes, then approve that one preview. Original bytes are rechecked before application; recovery copies and per-file receipts remain in app storage. Only Markdown, TXT, BIB, TEX and CSV are supported. No commands, folder inventory or file deletion. Recovery requires another preview and approval. Close other editors while applying; this is not OS isolation.

About Kosh

Kosh is a local research desk for sources, writing and references.

Development assistance

Built with OpenAI Codex for implementation, integration, testing, packaging and documentation, and Anthropic Claude for design and independent reviews. See the included CREDITS.md for details.

Workflow inspiration

Beeblio by Al Harkan (alharkan7) inspired the research workflow. Kosh uses original local application code; no Beeblio code or assets were copied.

Source & dependencies

Application source is licensed under AGPL-3.0-only. Your imported papers, notes and datasets are not relicensed. Python, SQLite, PyMuPDF, python-docx, lxml, Edge and the Windows launcher retain their respective third-party terms. Read the included licence and notices.

Privacy boundaries

Managed documents and writing stay in local storage. Public Discover sends only the query you explicitly type. Local Ollama uses bounded excerpts. Kosh passes the content you authorize to the selected installed agent; its CLI may add provider instructions or environment information. Suppression is configured, but has not been independently verified for live requests. No automatic full-paper downloads or private-library uploads occur.

Other agent products are not generic command targets. A future provider adapter requires a fixed invocation, explicit preview and the same proposal-only contract.

Import bibliography

Review RIS, BibTeX or CSL JSON records before importing reference metadata. This does not import full papers.

Insert data table

Paste tab separated cells or choose a CSV/TSV file. Review exact rows before insertion. This creates a draft table without analysis or calculated results.

The first row becomes column headings. Unequal row widths are refused. Cell line breaks become spaces in the Markdown table; source files are unchanged.

Local semantic search

Choose an already installed embedding model and explicitly build the local source index. No model is downloaded. Semantic matches are leads to inspect, not proof that a claim is supported.

Create an OCR copy

OCR creates a separate managed text derivative from this selected PDF page. The imported original stays intact. Recognition may misread words and numbers; compare the copy with the page.
